CipherON

Secure vault for Android // offline first

CipherON is a password manager for Android that keeps your logins, notes, one-time-code secrets and files in a vault that is encrypted on your phone. It works fully offline. There are no accounts to create, no ads and no tracking.

What it does

  • Encrypted vault (SQLCipher, AES-256) protected by a master password (Argon2id key derivation) and optional fingerprint unlock.
  • Entries with several categories, extra usernames, passwords, PINs and websites, attachments, password history and an archive.
  • Password, passphrase and PIN generator; one-time codes (TOTP); security statistics.
  • Import from many password managers; export to CSV, Excel and PDF; encrypted backup files.
  • Optional backup to your own Google Drive (a folder named CipherON) and optional sync to your own WebDAV server.
  • Auto-lock, screenshot protection, clipboard auto-clear and an optional self-destruct after wrong passwords.
Your data stays yours. The developer runs no servers for CipherON and receives none of your data. Read the privacy policy.

Google Drive backup

If you choose to connect Google Drive, CipherON asks only for permission to see and manage the files and folder it creates itself (the drive.file permission). It uploads the already-encrypted backup file to a folder named CipherON in your Drive. See the privacy policy for details.
